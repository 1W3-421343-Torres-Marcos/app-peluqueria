# Releases — documentación por versión

Esta carpeta conserva una copia documental de cada actualización instalable.

## Estructura

Cada versión usa una carpeta `docs/releases/<version>/` con:

- `changelog.md`: cambios incluidos en esa versión.
- `updates-plan.md`: tablero y registro de avance de esa actualización.
- `diagnostico.md`: causa, evidencia y reproducción cuando hubo una falla reportada.
- `verificacion.md`: pruebas, lint, APK y firma.

Los archivos globales `docs/changelog.md` y `docs/updates-plan.md` siguen siendo índices generales. Las carpetas por versión son el archivo histórico detallado.
